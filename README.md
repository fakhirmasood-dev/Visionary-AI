# Visionary-AI
The Project contain an AI-driven congnitive system which interprets real world scenes in realtime.
The Project is build in django and it is using Gemini api.<br>
<h2>Key Features</h2>
<p>It has three Features</p><br>
<h3>1.History:</h3><br>
   It will the scene in internet and will provide you history of it.If it does not have real history it will generate fake history.<br>
<h3>2.Future:</h3><br>
  It will predict the future based on history of scene.if it does not have real history then it will predict future by its own.<br>

<h3>3.Present:</h3>
  It will explain the current scene with complete details.

Installation
</h2>
<h3>Clone the repository</h3>
<p>git clone https://github.com/fakhirmasood-dev/Visionary-AI<br>
cd Visionary-AI<p>

<h3>Create a Vistual environment</h3>
<p>python -m venv venv<br>
Activate it:
<p>
<h4>Windows</h4>
<p>venv\scripts\activate</p>
<h4>Linux/macOS</h4>
<p>source venv/bin/activate</p>
<h3>Install dependencies</h3>
<p>pip install -r requirements.txt</p>
<h3>Apply migrations</h3>
<p>python manage.py migrate</p>
<h3>Run the development server</h3>
<p>python manage.py runserver<br>
Open this url in browser http://127.0.0.1:8000/FM-Mart/home</p>
<h3>Environment Variables</h3>
<p>create .env file and provide all environment variables.</p>
